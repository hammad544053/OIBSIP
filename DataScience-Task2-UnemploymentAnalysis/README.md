# Unemployment Analysis & Forecasting with Python

**Oasis Infobyte Internship (OIBSIP)**  
**Track:** Data Science  
**Task:** Task 2 — Unemployment Analysis with Python  

---

## 📌 Project Overview
This project presents an exploratory data analysis (EDA) and machine learning forecasting model built on historical Indian unemployment data. It analyzes regional and temporal unemployment trends with a particular focus on the economic impacts observed during pre-COVID and post-COVID periods.

The final machine learning pipeline is served via a responsive Flask web application for interactive real-time predictions.
